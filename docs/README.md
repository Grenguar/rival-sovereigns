# Sovereign

*An indirect-control fantasy kingdom simulation for the browser.*

You are the Sovereign. You build guilds, set the tax rate, and post gold bounties on
flags. You do **not** command anyone. Heroes spawn with their own names, stats and
temperaments, and decide for themselves what to do — hunt, shop, explore, flee, or sit
in the inn drinking your economy's gold. Your only levers are architecture and money.

The game is won by making self-interest point in a useful direction.

**Status:** pre-alpha. Design complete, implementation starting at milestone 0.
**Stack:** TypeScript (strict) · Vite · PixiJS · React · Vitest
**Target:** single-player, one mission, 80 agents at 60 fps, no server.

---

## Quickstart

```bash
pnpm install
pnpm pregen        # generate curve lookup tables + placeholder sprites + atlas
pnpm dev           # http://localhost:5173
pnpm test          # headless simulation suite
pnpm lint          # includes determinism rule enforcement
```

`pnpm pregen` must run before `dev` on a fresh clone — the curve tables and sprite
atlas are generated artefacts, not hand-written source.

---

## The three rules

Everything else is negotiable. These are not.

1. **The simulation is deterministic.** Same seed plus same commands produces a
   byte-identical world on every browser engine. See `docs/03-determinism.md`.
2. **`src/core/**` is pure.** No `pixi.js`, no `react`, no DOM. It runs headless in
   Node, which is what makes the whole test strategy possible.
3. **`pnpm test` stays green.** Especially `replay.spec.ts`. A failing determinism
   hash is a blocking bug, never a tolerance to widen.

## Repository layout

```
src/
  core/            deterministic simulation — zero rendering dependencies
    ai/            utility scoring, GOAP planner, sensors, henchman FSMs
    systems/       combat, economy, construction, spawning, flags, progression
    spatial/       grid, A*, flow fields, spatial hash, isometric projection
  content/         declarative data: classes, buildings, monsters, names, maps
  render/          PixiJS — reads world state, never writes it
  ui/              React shell over the canvas
tools/             build-time generators: curves, sprites, atlas, credits
tests/             headless simulation tests
docs/              this documentation set
```

## Ownership

`src/core/types.ts` and `src/core/world.ts` are human-owned. Agents propose changes to
them; they do not edit them. Everything else belongs to a track — see `AGENTS.md` §3.
